# Green Star Skin Assets

This directory contains themed visual assets for the Green Star skin.

## Asset Files

- `player.png` - Green star player sprite (placeholder)
- `ghost.png` - Comet tail ghost sprites (placeholder)
- `powerup.png` - Star shard powerup sprites (placeholder)
- `pellet.png` - Stardust dot pellet sprite (placeholder)

## Specifications

- Base tile size: 64px
- Supported scales: 1x, 2x
- Format: PNG with transparency
- Max dimensions: 2048x2048

## Status

Currently using placeholder assets. Production assets to be provided by design team.
