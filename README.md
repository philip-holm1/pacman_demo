# Pacman Demo — Modern Powerups

Run placeholder loop:

```powershell
python -m pacman
```
(After installation via editable mode or src path inclusion; fallback: `python -m src.pacman`.)

Install dependencies:
```powershell
python -m pip install -r requirements.txt
```
