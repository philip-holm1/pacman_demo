# Quickstart — Enable Green Star Skin

1. Open the game main menu.
2. Enter Settings > Skin.
3. Select "Green Star" and confirm.
4. Start a new game; the player appears as a green star; ghosts/powerups/pellets use theme assets.
5. To revert, go to Settings > Skin and choose "Default".

Notes
- Selection persists across restarts.
- If a themed asset fails to load, the game falls back to default for that category.
